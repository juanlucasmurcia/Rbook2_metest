Chapter 6 interpretacion del levene test

Se obtuvo un valor p de aproximadamente 0.905, que es mayor a 0.05. Por lo tanto, no se encuentran diferencias significativas entre las varianzas de los grupos.

6.1 Comparaciones Post-Hoc del Kruskal-Wallis

Dado que el test de Kruskal-Wallis solo indica que existe diferencia entre algún grupo, se aplica una comparación por pares para identificar cuáles orígenes difieren entre sí:

pairwise.wilcox.test(df$mpg, df$origin, p.adjust.method = "bonferroni")
