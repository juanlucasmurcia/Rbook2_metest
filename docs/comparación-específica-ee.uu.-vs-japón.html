Chapter 7 Comparación específica: EE.UU. vs Japón

Dado que mpg no presenta comportamiento normal (verificado previamente con Shapiro-Wilk), se utiliza la prueba de Mann-Whitney en lugar del t-test:

usa   <- df %>% filter(origin == "usa") %>% pull(mpg)
japon <- df %>% filter(origin == "japan") %>% pull(mpg)

wilcox.test(usa, japon)
## 
##  Wilcoxon rank sum test with continuity correction
## 
## data:  usa and japon
## W = 2499.5, p-value < 2.2e-16
## alternative hypothesis: true location shift is not equal to 0

7.1 interpretacion del wilcox

El valor p obtenido es mucho menor que 0.05, por lo que existe una diferencia estadísticamente significativa entre ambos grupos.

7.2 interpretacin de el tamaño del efecto

El tamaño del efecto de la prueba de Wilcoxon entre los automóviles de Estados Unidos y Japón fue de aproximadamente r = 0.55. Esto indica que existe una diferencia de magnitud moderada entre ambos grupos en cuanto al rendimiento (mpg).
