Chapter 4 interpretacion de resumen estadistico

se observa una variabilidad considerable entre los automóviles, especialmente en variables como displacement, horsepower y weight. Además, las diferencias entre la media y la mediana en algunas variables indican que sus datos no están distribuidos de manera completamente simétrica.

  • Diagramas de cajas y bigotes de cada variable:
library(patchwork)

p1 <- df %>% ggplot(aes(x = "", y = cylinders)) +
  geom_boxplot(fill = "#1f77b4", alpha = 0.7) + labs(x = "", y = "Cilindros") + theme_bw()

p2 <- df %>% ggplot(aes(x = "", y = displacement)) +
  geom_boxplot(fill = "#2ca02c", alpha = 0.7) + labs(x = "", y = "Cilindrada") + theme_bw()

p3 <- df %>% ggplot(aes(x = "", y = horsepower)) +
  geom_boxplot(fill = "#d62728", alpha = 0.7) + labs(x = "", y = "Potencia") + theme_bw()

p4 <- df %>% ggplot(aes(x = "", y = weight)) +
  geom_boxplot(fill = "#9467bd", alpha = 0.7) + labs(x = "", y = "Peso") + theme_bw()

p5 <- df %>% ggplot(aes(x = "", y = acceleration)) +
  geom_boxplot(fill = "#ff7f0e", alpha = 0.7) + labs(x = "", y = "Aceleración") + theme_bw()

(p1 + p2 + p3) / (p4 + p5)

#interpretacion del boxplots

Se observa mayor dispersión en cilindrada, potencia y peso, además de varios valores atípicos. En cylinders la mayoría de los vehículos se concentra entre 4 y 6 cilindros, mientras que acceleration presenta una distribución más concentrada.
