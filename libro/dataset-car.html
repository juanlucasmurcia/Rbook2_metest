2.4 Análisis exploratorio completo de variables numéricas

  • Asegurémonos de que horsepower esté en formato numérico (en el archivo original los faltantes vienen como “?”):
df <- df %>%
  mutate(horsepower = as.numeric(horsepower))
  • Resumen estadístico de todas las variables numéricas:
df %>%
  select(mpg, cylinders, displacement, horsepower, weight, acceleration, model_year) %>%
  pivot_longer(everything(), names_to = "variable", values_to = "valor") %>%
  group_by(variable) %>%

2.6 Comparaciones Post-Hoc del Kruskal-Wallis

Dado que el test de Kruskal-Wallis solo indica que existe diferencia entre algún grupo, se aplica una comparación por pares para identificar cuáles orígenes difieren entre sí:

{rposthoc-kruskal} pairwise.wilcox.test(df$mpg, df$origin, p.adjust.method = "bonferroni")
